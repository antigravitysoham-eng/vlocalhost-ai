Troubleshooting.

The five things people actually hit.

Windows says the publisher is unknown
Expected. The installer is not code-signed — a certificate costs money and that was a deliberate decision — so SmartScreen warns on every download. Choose More info → Run anyway. To verify first, every release publishes a .sha256 beside the installer: run Get-FileHash vlocalhost-…-setup.exe and compare the two strings.
macOS says the app cannot be opened
Also expected, for the same reason: the app is ad-hoc signed rather than notarized, because notarization requires a paid Apple developer account. Open System Settings → Privacy & Security, scroll to the message about Vlocalhost and press Open Anyway. You do this once.
Chrome says “Failed — Virus scan failed”
Not a detection. Chrome hands the finished download to Windows to be scanned and that call failed — usually third-party antivirus, a managed work laptop, or a Defender service that is not running. The file is never reported as malicious; the scan simply never answered. Open Downloads (Ctrl+J) and press Retry.
The microphone is not picked up
Open Settings → What to listen to, choose the microphone by name, and press Refresh if you plugged it in after the app opened. From a terminal, python vlocalhost.py --devices lists everything the app can see and what your current setting resolves to.
There are no summaries, only transcripts
Summarising uses Ollama, running locally. Install it and run ollama pull llama3.2. The transcript is always written regardless — a missing summariser never costs you the meeting.

Still stuck? Send a diagnostic report — the app writes one you can read before you send it.
